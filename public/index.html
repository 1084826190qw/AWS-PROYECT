Características

Funcionalidades principales del sistema

Gestión de Clientes

Registro, consulta y administración de datos de clientes de forma centralizada.

Gestión de Vehículos

Catálogo completo con marcas, modelos, años y disponibilidad de stock.

Registro de Ventas

Seguimiento detallado de cada transacción con datos del comprador y vehículo.

Gestión de Pagos

Control de pagos, cuotas y estados financieros por venta realizada.

Persistencia de Datos

Almacenamiento robusto con MySQL y PostgreSQL para alta disponibilidad.

Arquitectura en Contenedores

Servicios dockerizados para despliegue rápido, aislado y reproducible.
